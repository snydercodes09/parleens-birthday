# 🎂 Happy Birthday, Parleen! 💕

A beautiful, animated birthday website created with love for Parleen's 19th birthday.

## ✨ Features

- **🎬 Hero Section** - Full-screen video background with animated text and mute controls
- **💝 Our Story** - A heartfelt timeline of your journey together
- **📸 Memories Gallery** - Infinite-scrolling photo/video carousel with hover-to-expand cards
- **💕 Things I Love About You** - Draggable card stack with personalized messages
- **🎁 Birthday Wishes** - Special birthday message with confetti effects
- **🎊 Finale** - Grand finale with floating hearts and celebration animations

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: GSAP (GreenSock Animation Platform)
- **Effects**: Canvas Confetti, Custom SVG animations

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- pnpm (recommended)

### Installation

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build

# Start production server
pnpm start
```

## 📁 Project Structure

```
birthday-website/
├── app/                    # Next.js App Router
│   ├── globals.css        # Global styles & Tailwind
│   ├── layout.tsx         # Root layout
│   └── page.tsx           # Main page
├── components/
│   ├── effects/           # Visual effects (cursor, hearts)
│   ├── sections/          # Page sections (Hero, Memories, etc.)
│   └── ui/                # UI components (MuteButton)
├── lib/                   # Utilities and animations
├── public/
│   ├── images/            # Memory photos
│   ├── videos/            # Background & memory videos
│   └── audio/             # Background music
└── tailwind.config.ts     # Tailwind configuration
```
